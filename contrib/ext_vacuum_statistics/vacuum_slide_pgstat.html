PostgreSQL Cumulative Statistics & Custom Kinds

How the pgstat framework stores, persists, and serves statistics — and how extensions plug in

Backends
⚙
Generate statistics
Any backend doing work:
queries, vacuum, replication...
📝
Write to shared hash table
Key: (kind, database OID, object OID)
Lock entry, add deltas, unlock
➕ Counters are cumulative — only grow
Shared Memory (dshash)
🗄
Dynamic hash table
Entries created on first access,
grow as new objects appear
🔒
Per-entry LWLock
Multiple backends can update
different entries concurrently
📦
Built-in + custom kinds
Relations, functions, WAL, I/O...
Extensions register their own kinds
Disk Persistence
💾
Checkpointer writes on shutdown
Serializes hash table entries
to pg_stat/pgstat.stat
🔄
Loaded on startup
File deserialized back
into shared memory hash
⚠
Crash = partial loss
Only clean shutdown guarantees
all stats are saved
Custom Kinds (Extensions)
🧩
Register at startup
pgstat_register_kind()
in shared_preload_libraries
📐
Define struct and size
Extension decides what fields
to store per entry
✅
Get everything for free
Shared memory, locking,
persistence, reset, snapshots
ext_vacuum_statistics registers 2 custom kinds with write_to_file = true and accessed_across_databases = true — the pgstat framework handles the rest.

Inside the Cumulative Stats Collector

How an entry is found, locked, updated, and read back

Find or Create Entry
🔑
Hash lookup by key
(kind, database OID, object OID)
in shared dshash table
➕
If not found — create slot
Allocate new entry in shared memory,
initialize counters to zero
Lock & Update
🔒
Acquire per-entry LWLock
Each entry has its own lock —
no global contention
➕
Add deltas to counters
entry.field += delta
Release lock
Shared dshash Table
🗄
Dynamic shared hash
Grows as new objects appear.
Built-in + custom kinds
in the same table.
💾
Serialized to disk
On clean shutdown → pgstat.stat
On startup → deserialized back
Read Path
🔍
Hash lookup by same key
No lock needed for reads —
uses consistent snapshot
📋
Return to SQL view
Directly from shared memory,
no disk I/O
